# A.F.C.D.E — Académie Football Club Dieu-Est

Site vitrine statique prêt à être déployé sur **Vercel**.

## Déploiement sur Vercel
1. Crée un nouveau dépôt GitHub.
2. Dépose `index.html`, `logo.jpeg` et ce fichier `README.md` à la racine du dépôt.
3. Sur Vercel, choisis **Add New → Project**, puis importe le dépôt GitHub.
4. Garde les réglages par défaut : aucun framework ni commande de build n'est nécessaire.
5. Clique sur **Deploy**.

## Images à ajouter plus tard
